# 🧬 SmartHealth 360 — AI Healthcare Intelligence Ecosystem

![SmartHealth 360 Banner](https://images.unsplash.com/photo-1576091160550-2173dad99901?auto=format&fit=crop&q=80&w=2070&ixlib=rb-4.0.3)

**SmartHealth 360** is a production-ready, AI-driven healthcare intelligence platform designed to transform how users manage their medical journey. Built with a cinematic "Tesla-inspired" HUD aesthetic, the platform integrates deep-layer AI analysis, holographic report scanning, and a universal AI Companion that acts as the centralized brain of the entire ecosystem.

---

## 🚀 Key Features

### 🔍 Neural Report Synthesis (OCR + AI)
*   **Holographic Scanning**: Immerse yourself in a circular HUD scanning experience that extracts medical data in real-time.
*   **Line-by-Line Synthesis**: AI parses complex medical reports (blood tests, lipid profiles) and compares biomarkers against clinical thresholds.
*   **Contextual Explanations**: "Explain This" AI cards translate medical jargon into simple, actionable human language.
*   **Vector Shift Tracking**: Automatically track historical health trends with percentage-based improvement metrics.

### 🤖 SmartHealth AI Companion (Universal Brain)
*   **Module Synchronization**: AI chat choices dynamically update the entire platform (e.g., choosing Ayurveda updates the Wellness and Expert Network modules).
*   **Symptom Triage**: Proactively routes users to either **Holistic Care (Ayurveda)** or **Clinical Care (Doctors)** based on reported symptoms.
*   **Medication Intelligence**: Search for bio-equivalent substitutes and receive dosage safety warnings.
*   **Emergency Mode**: Instant triggering of emergency protocols, hospital mapping, and paramedic summary generation.

### 💊 Bio-Records & Neural Scanner
*   **Digital/Physical Rx Sync**: Scan physical prescriptions via camera or upload digital files.
*   **Interaction Check**: Automatic cross-referencing of new medications against existing regimens and genomic profiles.
*   **Refill Logistics**: Autonomous pharmacy coordination and refill tracking.

### 🌿 Holistic Wellness Dashboard
*   **Zone-Based Themes**: UI dynamically shifts its visual theme based on your Health Zone (Red/Orange/Green).
*   **Ayurveda Integration**: Tailored herbal protocols, breathing exercises (Pranayama), and nutrition plans synchronized with your latest bio-scans.

## 🛠️ Technology Stack

*   **Frontend**: React.js, Tailwind CSS v4, Framer Motion (Cinematic Animations)
*   **Icons**: Lucide React
*   **State Management**: React Context API (High-Efficiency Global Sync)
*   **OCR/AI Simulation**: Advanced Pattern Matching & Medical Knowledge Base Engine
*   **Persistence**: Real-time LocalStorage Synchronization (Firebase Ready)

## 📦 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/1at24cs054-rgb/SmartHealth_360.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Launch the Neural Interface:**
   ```bash
   npm run dev
   ```

4. **Access the platform:**
   Open `http://localhost:5173` in your browser.
